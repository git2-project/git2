## 1. Approach

We will build git2 with **Agile (Scrum)**.

All members use Claude (Claude Code) as an AI assistant. Every change it makes is reviewed by a teammate.

## 3. How We Work

- Sprints are two weeks long; only the first sprint is one week.
- Each sprint starts with planning and ends with a demo and a retrospective.
- Members share a short daily update in the team chat.
- Every Friday all work is merged and tested together.
- Tasks are tracked as user stories on the GitHub Projects board.
- Every pull request needs tests and one review before merge.
